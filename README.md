# FoobarRemote

Мобильный пульт управления для [foobar2000](https://www.foobar2000.org/) через
[Beefweb](https://github.com/hyperblast/beefweb) — HTTP-интерфейс плагина
`foo_beefweb`. Приложение позволяет управлять воспроизведением и просматривать
медиатеку с телефона, находясь в одной сети с компьютером, на котором запущен
foobar2000.

Написано на TypeScript с использованием React Native 0.86.

## Возможности

-   Управление воспроизведением: play/pause, предыдущий/следующий трек,
    перемотка по волновой форме, регулировка громкости.
-   Отображение обложки альбома и информации о текущем треке.
-   Навигация по медиатеке: жанры → исполнители → альбомы → треки,
    с запуском воспроизведения альбома или трека по тапу.
-   Локальный импорт и индексация медиатеки при запуске — навигация
    по жанрам, исполнителям и альбомам работает по локальным данным.
-   Экран плейлистов: список пользовательских плейлистов foobar2000
    с запуском воспроизведения по тапу.
-   Настройка адреса и порта сервера Beefweb с проверкой корректности ввода.
-   Локальный импорт и индексация медиатеки при запуске: навигация
    по жанрам, исполнителям и альбомам выполняется по данным, загруженным
    с сервера один раз при старте.
-   Светлая, темная и системная темы оформления.
-   Интерфейс на шести языках: английском, русском, немецком, французском,
    испанском и китайском (язык выбирается автоматически по системной локали
    и может быть изменен в настройках).

## Требования

-   Node.js `>= 22.11.0`
-   JDK и Android SDK (для сборки под Android)
-   Xcode и CocoaPods (для сборки под iOS); для удобства используется Bundler
-   Настроенное окружение React Native — см.
    [Set Up Your Environment](https://reactnative.dev/docs/set-up-your-environment)

Со стороны плеера:

-   foobar2000 с установленным плагином
    [`foo_beefweb`](https://github.com/hyperblast/beefweb#installation);
-   включенный HTTP-сервер Beefweb (по умолчанию порт `8880`);
-   телефон и компьютер в одной сети.

## Установка и запуск

Установите JavaScript-зависимости:

```sh
npm install
```

Для iOS при первой настройке установите Bundler и зависимости CocoaPods:

```sh
bundle install
bundle exec pod install
```

Запустите Metro — сборщик JavaScript для React Native:

```sh
npm start
```

В отдельном терминале соберите и запустите приложение на нужной платформе:

```sh
# Android
npm run android

# iOS
npm run ios
```

Приложение можно собирать и напрямую из Android Studio или Xcode — тогда Metro
все равно должен быть запущен.

## Подключение к foobar2000

### 1. Установите и настройте Beefweb

Установите в foobar2000 плагин `foo_beefweb` и убедитесь, что его HTTP-сервер
запущен (File → Preferences → Tools → Beef Web).

### 2. Создайте плейлист-каталог вручную

Приложение импортирует медиатеку из служебного плейлиста с точным именем
`beefweb-catalog`. Его нужно один раз создать и наполнить в foobar2000
вручную:

1. В foobar2000 создайте новый плейлист и переименуйте его точно в
   `beefweb-catalog` (имя должно совпадать посимвольно).
2. Наполните его всей медиатекой: откройте **Media Library → Album List**
   (или **Search**), выделите всё содержимое библиотеки и отправьте в этот
   плейлист командой **Send to playlist**.

Важные свойства каталога:

-   Плейлист **только читается**: приложение никогда не создает, не очищает
    и не пересобирает его — содержимым управляет пользователь. Это позволяет
    нескольким устройствам работать с одним сервером без конфликтов.
-   Каталог должен быть непустым; максимальный поддерживаемый размер —
    100 000 треков.
-   Каталог также служит источником позиций треков при загрузке обложек,
    поэтому после изменения медиатеки обновите его содержимое и перезапустите
    приложение — библиотека импортируется заново при каждом запуске.

### 3. Укажите адрес сервера в приложении

При первом запуске приложения откроется экран настройки: укажите адрес
компьютера (например, `192.168.1.100`) и порт сервера Beefweb
(обычно `8880`). Адрес и порт хранятся на устройстве и могут быть изменены
позже в разделе настроек.

### Плейлист воспроизведения

Помимо каталога приложение использует обычный плейлист с именем `beefweb`:
он создается и очищается автоматически при выборе альбома и содержит только
его треки. Вручную создавать его не нужно.

## Требования к организации медиатеки

Структура жанров, исполнителей и альбомов строится исключительно по тегам
файлов, поэтому корректная разметка медиатеки обязательна.

### Используемые теги

| Тег            | Назначение          |
| -------------- | ------------------- |
| `title`        | Название трека      |
| `artist`       | Исполнитель трека   |
| `album artist` | Исполнитель альбома |
| `album`        | Название альбома    |
| `genre`        | Жанр                |
| `date`         | Год выпуска         |
| `tracknumber`  | Номер трека         |
| `totaltracks`  | Всего треков        |
| `discnumber`   | Номер диска         |
| `totaldiscs`   | Всего дисков        |

### Правила обработки тегов

-   Из многозначных тегов используется только первое значение.
-   Если тег `album artist` отсутствует, исполнителем альбома считается
    `artist`.
-   Отсутствующий `genre` попадает в раздел «?».
-   Отсутствующие `discnumber` и `totaldiscs` считаются равными 1 —
    для однодисковых альбомов их можно не заполнять.
-   Альбом определяется сочетанием `album artist + album`: у всех треков
    одного альбома эти два тега должны совпадать посимвольно, иначе альбом
    распадется на несколько.
-   Порядок треков внутри альбома определяется номером диска (`discnumber`),
    затем номером трека (`tracknumber`). Для аккуратной сортировки
    заполняйте оба тега у всех треков.

### Требования к музыкальным файлам

-   **Один трек — один отдельный аудиофайл.** Приложение всегда считает,
    что файл содержит ровно один трек (индекс вложенной композиции 0),
    поэтому релизы «один файл + CUE-разметка» не поддерживаются: все треки
    такого файла имеют одинаковый путь и при импорте сливаются в один.
-   Аудиокодек значения не имеет — подойдет любой формат, который декодирует
    ваш foobar2000 (FLAC, MP3, WAV и т.д.): приложение читает только теги
    и пути, само воспроизведение выполняет плеер.
-   Все файлы должны входить в Media Library foobar2000, иначе их нельзя
    добавить в плейлист-каталог.
-   Дубли одного файла в плейлисте-каталоге не приводят к ошибке (берется
    первое вхождение пути), но лучше их избегать.

### Обложки альбомов

Обложки запрашиваются через artwork API Beefweb, который опирается на штатный
поиск обложек foobar2000. Подойдет любой из вариантов:

-   встроенная обложка (Front Cover) внутри аудиофайлов;
-   внешний файл обложки в каталоге альбома с именем, подходящим под шаблоны
    поиска foobar2000 (типично `cover.jpg`, `folder.jpg` и т.п.). Шаблоны
    настраиваются в **File → Preferences → Display → Album Art**.

Замечания:

-   Обложка запрашивается по первому треку альбома, поэтому достаточно одной
    обложки на альбом — либо в каждом файле, либо одним внешним файлом
    в каталоге альбома.
-   Отсутствие обложки — нормальная ситуация: приложение показывает
    заглушку, а не ошибку.

### Многодисковые альбомы

Номер диска берется только из тега `discnumber`, а названием диска служит
имя непосредственно родительского каталога файла. Поэтому каждый диск
рекомендуется класть в отдельный подкаталог:

```text
Music/
└── Adele/
    └── 19/
        ├── cd_1/
        │   ├── 01. Daydreamer.flac
        │   └── ...
        └── cd_2/
            ├── 01. That's It.flac
            └── ...
```

У всех файлов такого альбома должны быть проставлены `discnumber`
(1, 2, …) и одинаковый `totaldiscs`.

### Организация каталогов

Навигация по жанрам и исполнителям строится по тегам, поэтому имена каталогов
на нее не влияют. Требования к структуре минимальны, но их стоит соблюдать:

-   Файлы одного альбома держите в одном каталоге (или в его подкаталогах —
    для многодисковых релизов).
-   Для многодисковых альбомов каждый диск кладите в отдельный подкаталог:
    имя этого подкаталога отображается как название диска.
-   Внешний файл обложки кладите в корень каталога альбома.

Рекомендуемая структура:

```text
Music/
└── Adele/
    ├── [2008] 19/
    │   ├── cover.jpg              # внешняя обложка (или встроенная в файлы)
    │   ├── 01. Daydreamer.flac
    │   └── ...
    └── [2011] 21/
        ├── cd_1/
        │   ├── cover.jpg          # либо обложка на уровне альбома
        │   ├── 01. Rolling in the Deep.flac
        │   └── ...
        └── cd_2/
            └── ...
```

После пополнения или изменения медиатеки обновите содержимое плейлиста
`beefweb-catalog` и перезапустите приложение: библиотека импортируется
заново при каждом запуске.

## Структура проекта

-   `App.tsx` — точка входа приложения.
-   `src/screens/` — экраны приложения и логика уровня экрана.
-   `src/components/` — переиспользуемые UI-компоненты, элементы управления,
    иконки.
-   `src/navigation/` — стековый навигатор (React Navigation).
-   `src/services/` — работа с сетью, API Beefweb, настройками,
    воспроизведением и загрузкой данных.
-   `src/library/` — доменные типы, хранилище, импорт и индексация медиатеки.
-   `src/i18n/` — локализация и переводы (`en`, `ru`, `de`, `fr`, `es`, `zh`).
-   `src/theme/` — общие цвета, типографика и темы оформления.
-   `src/types/` — общие типы TypeScript, включая параметры навигации.
-   `__tests__/` — тесты Jest.
-   `android/`, `ios/` — нативные проекты.

## Разработка и тестирование

Тесты выполняются через Jest с пресетом `@react-native/jest-preset`:

```sh
npm test                 # весь набор тестов
npx jest --runInBand     # последовательный запуск
npx jest __tests__/App.test.tsx -t "renders correctly"
```

Перед отправкой изменений рекомендуется прогнать линтер, проверку типов и
тесты:

```sh
npm run lint
npm run typecheck
npm test
```

## Диагностика неполадок

-   Если приложение не подключается к плееру, проверьте, что Beefweb-сервер
    запущен, порт совпадает с указанным в настройках, а брандмауэр компьютера
    разрешает входящие подключения.
-   Если импорт медиатеки завершается ошибкой об отсутствии плейлиста,
    создайте плейлист `beefweb-catalog` и наполните его всей библиотекой
    (см. «Подключение к foobar2000»).
-   Если в разделах жанров или исполнителей много записей «?», значит у
    файлов не заполнен тег `genre` — разметьте теги и повторите импорт.
-   При устаревшем состоянии Metro перезапустите его командой
    `npx react-native start --reset-cache`.
-   Общие проблемы окружения React Native описаны в официальном
    [Troubleshooting](https://reactnative.dev/docs/troubleshooting).
