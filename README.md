# FoobarRemote

Мобильный пульт для музыкального сервера на базе [MPD](https://www.musicpd.org/)
(Music Player Daemon), такого как [moOde Audio](https://moodeaudio.org/).
Приложение управляет воспроизведением и просматривает медиатеку с телефона,
находясь с сервером в одной сети. Общение с сервером идет по нативному
протоколу MPD через TCP — HTTP-плагины и промежуточные слои не требуются.

Написано на TypeScript с использованием React Native 0.86 и React 19.

## Возможности

-   Управление воспроизведением: play/pause, предыдущий/следующий трек,
    перемотка по волновой форме, громкость и mute.
-   Отображение обложки альбома и информации о текущем треке.
-   Навигация по медиатеке: жанры → исполнители → альбомы → треки;
    запуск воспроизведения альбома или трека по тапу.
-   Экран плейлистов: сохраненные плейлисты MPD с запуском воспроизведения.
-   Событийное обновление состояния: приложение подписывается на события
    сервера (`idle player/mixer/playlist/options`).
-   Настройка адреса и порта сервера с проверкой связи перед сохранением.
-   Светлая, темная и системная темы оформления.
-   Интерфейс на шести языках: английском, русском, немецком, французском,
    испанском и китайском (язык выбирается по системной локали
    и меняется в настройках).

## Требования

-   Node.js `>= 22.11.0`
-   JDK и Android SDK (для сборки под Android)
-   Xcode и CocoaPods (для сборки под iOS); для удобства используется Bundler
-   Настроенное окружение React Native — см.
    [Set Up Your Environment](https://reactnative.dev/docs/set-up-your-environment)

Со стороны сервера:

-   работающий MPD (в moOde включен по умолчанию);
-   доступный TCP-порт MPD (по умолчанию `6600`);
-   телефон и сервер в одной сети.

## Установка и запуск

Установите JavaScript-зависимости:

```sh
npm install
```

Для iOS при первой настройке установите Bundler и зависимости CocoaPods:

```sh
bundle install
bundle exec pod install
```

Запустите Metro — сборщик JavaScript для React Native:

```sh
npm start
```

В отдельном терминале соберите и запустите приложение на нужной платформе:

```sh
# Android
npm run android

# iOS
npm run ios
```

Приложение можно собирать и напрямую из Android Studio или Xcode — тогда Metro
все равно должен быть запущен.

## Подключение к серверу

При первом запуске откроется экран настроек:

-   **URL** — адрес сервера: имя хоста или IP, например `moode.local`
    или `192.168.1.100`. Необязательный префикс `http://` или `https://`
    игнорируется; допускается указать порт прямо в адресе (`moode.local:6600`).
-   **Port** — порт MPD. Если поле пустое, используется порт из адреса
    или значение по умолчанию `6600`.

Адрес проверяется реальным TCP-соединением с командой `ping` и сохраняется
только при успехе. Значения хранятся на устройстве и меняются в настройках
в любой момент.

Ничего настраивать на сервере, кроме доступного порта MPD, не нужно:
медиатека читается напрямую из базы MPD, отдельный плейлист-каталог
не используется. Несколько устройств могут работать с одним сервером
одновременно, не мешая друг другу.

## Требования к медиатеке

Структура жанров, исполнителей и альбомов строится по тегам файлов,
поэтому корректная разметка медиатеки важна.

### Используемые теги

| Тег            | Назначение                      |
| -------------- | ------------------------------- |
| `title`        | Название трека                  |
| `artist`       | Исполнитель трека               |
| `album artist` | Исполнитель альбома             |
| `album`        | Название альбома                |
| `genre`        | Жанр                            |
| `date`         | Год выпуска                     |
| `track`        | Номер трека, допускается `3/12` |
| `disc`         | Номер диска, допускается `1/2`  |

### Правила обработки тегов

-   Из многозначных тегов используется только первое значение.
-   Если тег `album artist` отсутствует, исполнителем альбома считается
    `artist`.
-   Отсутствующий `genre` попадает в раздел «?».
-   Отсутствующий номер диска считается равным 1 — для однодисковых
    альбомов его можно не заполнять.
-   Альбом определяется сочетанием `album artist + album`: у всех треков
    одного альбома эти два тега должны совпадать, иначе альбом распадется
    на несколько.
-   Порядок треков внутри альбома определяется номером диска, затем номером
    трека. Составные значения `3/12` разбираются: число до слеша — номер,
    после — общее количество.
-   Если тег `title` отсутствует, названием трека становится имя файла
    без расширения.

### Требования к музыкальным файлам

-   **Один трек — один отдельный аудиофайл.** Релизы «один файл
    + CUE-разметка» в навигации по медиатеке не поддерживаются: все треки
    такого файла имеют один путь и при импорте сливаются в один. Строки
    CUE-альбомов в сохраненных плейлистах при этом показываются корректно —
    с метаданными, прочитанными с сервера.
-   Аудиокодек значения не имеет — подойдет любой формат, который декодирует
    ваш MPD: приложение читает только теги и пути, воспроизведение
    выполняет сервер.
-   Все файлы должны находиться в музыкальном каталоге MPD
    (`music_directory`), иначе их не будет в базе сервера.

### Обложки альбомов

Обложки запрашиваются напрямую у MPD: сначала `albumart` (файл-обложка
рядом с треком), затем `readpicture` (встроенная обложка в аудиофайле).
Подойдет любой из вариантов:

-   встроенная обложка (Front Cover) внутри аудиофайлов;
-   внешний файл обложки в каталоге альбома (типично `cover.jpg`,
    `folder.jpg` и т.п.).

Обложка запрашивается по первому треку альбома, поэтому достаточно одной
обложки на альбом. Отсутствие обложки — нормальная ситуация: приложение
показывает заглушку, а не ошибку. Загруженные обложки кэшируются
на устройстве и переживают перезапуск приложения.

### Многодисковые альбомы

Номер диска берется из тега `disc`, а названием диска служит имя
непосредственно родительского каталога файла. Каждый диск рекомендуется
класть в отдельный подкаталог:

```text
Music/
└── Adele/
    └── 19/
        ├── cd_1/
        │   ├── 01. Daydreamer.flac
        │   └── ...
        └── cd_2/
            ├── 01. That's It.flac
            └── ...
```

У всех файлов такого альбома должен быть проставлен `disc` (1, 2, …).

После пополнения или изменения медиатеки просто перезапустите приложение:
библиотека перечитывается из базы MPD при каждом запуске.

## Структура проекта

-   `App.tsx` — точка входа приложения.
-   `src/screens/` — экраны приложения и логика уровня экрана.
-   `src/components/` — переиспользуемые UI-компоненты, элементы управления,
    иконки.
-   `src/navigation/` — стековый навигатор (React Navigation).
-   `src/services/` — состояние воспроизведения, настройки, загрузка
    обложек и данных.
-   `src/services/mpd/` — клиент протокола MPD: соединения, парсер,
    команды плеера, плейлистов, каталога и обложек.
-   `src/library/` — доменные типы, хранилище, импорт и индексация медиатеки.
-   `src/i18n/` — локализация и переводы (`en`, `ru`, `de`, `fr`, `es`, `zh`).
-   `src/theme/` — цвета, типографика и темы оформления.
-   `src/types/` — общие типы TypeScript, включая параметры навигации.
-   `__tests__/` — тесты Jest.
-   `android/`, `ios/` — нативные проекты.

npx jest --runInBand     # последовательный запуск

и тесты:

```sh

npm test
```

## Диагностика неполадок

-   Если приложение не подключается к серверу, проверьте, что MPD запущен
    и принимает подключения на указанном порту (`6600` по умолчанию),
    а брандмауэр сервера разрешает входящие TCP-соединения.
-   Если медиатека пуста или импорт завершается ошибкой, проверьте, что
    музыкальный каталог MPD проиндексирован: файлы должны попадать в базу
    сервера (команда `listallinfo` возвращает их).
-   Если в разделах жанров или исполнителей много записей «?», значит у
    файлов не заполнен тег `genre` — разметьте теги и перезапустите
    приложение.
-   При устаревшем состоянии Metro перезапустите его командой
    `npx react-native start --reset-cache`.
-   Общие проблемы окружения React Native описаны в официальном
    [Troubleshooting](https://reactnative.dev/docs/troubleshooting).
