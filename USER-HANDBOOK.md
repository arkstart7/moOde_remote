# Руководство пользователя FoobarRemote

Справочник по работе с приложением: первый запуск, управление
воспроизведением, навигация по медиатеке, плейлисты и настройки.

Приложение работает с музыкальным сервером на базе MPD (например,
moOde Audio). Требования к серверу и медиатеке описаны в
[README.md](README.md) — перед первым запуском убедитесь, что MPD
доступен по сети.

## Первый запуск

1. Запустите приложение. На стартовом экране последовательно отображаются
   этапы запуска:
    - проверка сохраненных настроек;
    - загрузка медиатеки с сервера;
    - подготовка очереди воспроизведения.
2. Если настроек еще нет, откроется экран **Settings**:
    - **URL** — адрес сервера, например `moode.local` или `192.168.1.100`.
       Префикс `http://` вводить не нужно; можно указать порт прямо
       в адресе: `moode.local:6600`.
    - **Port** — порт MPD, обычно `6600`. Поле можно оставить пустым,
       если порт уже указан в URL.
3. Вернитесь назад кнопкой «Назад» (стрелка с подписью в шапке). Адрес
   будет проверен реальным соединением с сервером и сохранен, после чего
   запуск повторится: при успехе откроется экран альбомов, при ошибке —
   сообщение под формой. Пока идет проверка соединения, кнопка «Назад»
   заблокирована.

Медиатека перечитывается с сервера при каждом запуске приложения,
поэтому изменения в библиотеке подхватываются после перезапуска.

## Навигация

На главном экране воспроизведения шестеренка в шапке открывает настройки.
На остальных экранах внизу находится нижняя навигационная панель с пунктами:

-   **Genres** → **Artists** → **Albums** → **Tracks** — навигация
    по медиатеке;
-   **Playlists** — список плейлистов;
-   **Settings** — настройки.

Активный пункт подсвечен. На главный экран можно вернуться тапом
по мини-плееру внизу любого экрана библиотеки.

## Главный экран

На главном экране отображается обложка играющего альбома, название трека,
исполнитель, альбом, полоса прогресса и блок управления. Если воспроизводится
сохраненный плейлист, вместо обложки альбома показывается заглушка плейлиста.

### Жесты на обложке

| Жест         | Действие        |
| ------------ | --------------- |
| Свайп влево  | Следующий трек  |
| Свайп вправо | Предыдущий трек |

Вертикальные движения на обложке жест не активируют.

### Полоса прогресса

Полоса изображает трек в виде «волны»: проигранная часть выделена цветом.
Под полосой слева — текущее время, справа — длительность, в центре — номер
трека в источнике воспроизведения (`3 / 12`). Касание в любом месте полосы
перемотает трек на соответствующую позицию.

### Громкость

Слайдер громкости показывает уровень, полученный от сервера. Во время
перетаскивания значение показывается локально, а применяется после
отпускания пальца. Кнопка рядом со слайдером включает и выключает mute:
при включении громкость сервера обнуляется, при выключении — восстанавливается
прежнее значение.

### Кнопки воспроизведения

Кнопки «предыдущий», play/pause и «следующий» управляют текущим источником —
альбомом или плейлистом. «Предыдущий» неактивен на первом треке, «следующий» —
на последнем; на время выполнения команды кнопки кратко блокируются.

Если команда завершилась ошибкой, сообщение появится под кнопками.

## Мини-плеер

На экранах библиотеки (жанры, исполнители, альбомы, треки) внизу находится
компактный блок текущего воспроизведения: обложка, названия трека,
исполнителя и альбома, тонкая полоса прогресса с перемоткой и те же три
кнопки управления. Тап по обложке или подписям трека открывает главный экран.

## Навигация по медиатеке

Выбор фильтрует нижние уровни: жанр ограничивает список исполнителей,
исполнитель — список альбомов. Выбор сохраняется при переключении между
экранами меню.

### Жанры

Первым пунктом идет **All genres** (все альбомы), далее — список жанров
с количеством альбомов у каждого. Выбранный пункт подсвечивается.

### Исполнители

Список исполнителей с учетом выбранного жанра; число справа — количество
альбомов исполнителя в этом жанре. Пункт **All artists** снимает фильтр.

### Альбомы

Сетка альбомов по три колонки с обложками; заголовок сверху показывает
текущий контекст, например `Rock - Pink Floyd`. Тап по альбому загружает
его в очередь сервера и начинает воспроизведение с первого трека; карточка
текущего альбома подсвечена. Пока загрузка выполняется, сетка заблокирована.

Многодисковые альбомы упорядочены по дискам, затем по номерам треков.

### Треки

Список треков активного источника — текущего альбома или выбранного
плейлиста: порядковый номер, название, длительность. У многодисковых
альбомов треки сгруппированы по секциям с названием диска. Тап по треку
запускает его воспроизведение, текущий трек выделен.

## Плейлисты

Список сохраненных плейлистов сервера с количеством треков у каждого.
Служебные плейлисты (`Default`) и плейлисты без треков не показываются.
Тап по плейлисту загружает его в очередь и запускает воспроизведение
с первого трека; выбранный плейлист подсвечен, на время загрузки список
заблокирован.

В плейлисте могут быть треки, которых нет в медиатеке приложения
(например, строки CUE-альбомов) — они показываются с метаданными,
полученными с сервера.

## Настройки

Экран открывается шестеренкой в шапке главного экрана или пунктом Settings
в нижней навигационной панели.

-   **URL** и **Port** — те же поля подключения, что и при первом запуске.
    Измененные значения проверяются соединением с сервером и сохраняются
    только при успехе; если ничего не менялось, выход происходит без
    проверки.
-   **Language** — язык интерфейса: English, Русский, Deutsch, Français,
    Español или 中文. Выбор применяется мгновенно ко всем экранам
    и сохраняется отдельно от формы подключения. При первом включении язык
    выбирается по системной локали устройства.
-   **Theme** — тема оформления: System, Light или Dark. По умолчанию
    используется системная тема устройства.

Ошибки проверки выводятся списком под формой.

## Сообщения об ошибках

| Ситуация                          | Что делать                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------------- |
| Нет соединения с сервером         | Проверьте, что MPD запущен, адрес и порт верны, а брандмауэр разрешает TCP-подключения |
| Адрес или порт введены неверно    | Исправьте адрес хоста или укажите порт от 1 до 65535                                   |
| Не удалось прочитать медиатеку    | Проверьте, что музыкальный каталог MPD проиндексирован, и повторите запуск             |
| Медиатека пуста                   | Добавьте файлы в музыкальный каталог сервера                                           |
| Медиатека слишком велика          | В ней больше 200 000 треков — сократите содержимое каталога                            |
| Ошибка загрузки альбома/плейлиста | Проверьте доступность файлов на сервере и повторите попытку                            |
| Не удалось загрузить обложку      | Проверьте связь с сервером; отсутствие обложки само по себе ошибкой не является        |

Все сообщения показываются на языке интерфейса; техническая причина сбоя
добавляется к сообщению отдельной строкой.

## Данные на устройстве

Приложение хранит локально:

-   адрес и порт сервера;
-   выбранный язык интерфейса и тему оформления;
-   последний выбранный источник воспроизведения (альбом или плейлист),
    трек и позицию — восстанавливаются при запуске;
-   кэш обложек (переживает перезапуск и может очищаться системой
    автоматически).

Чтобы сбросить все данные, очистите данные приложения в настройках Android
или удалите и установите его заново.
