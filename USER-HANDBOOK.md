# Руководство пользователя FoobarRemote

Справочник по работе с приложением: первый запуск, управление
воспроизведением, навигация по медиатеке и настройки.

Требования к серверу (плагин Beefweb, плейлист-каталог, теги файлов)
описаны в [README.md](README.md) — перед первым запуском выполните шаги
из раздела «Подключение к foobar2000».

## Первый запуск

1. Убедитесь, что на сервере создан и наполнен плейлист `beefweb-catalog`
   (см. README).
2. Запустите приложение. На стартовом экране последовательно отображаются
   этапы запуска:
    - проверка сохраненных настроек;
    - загрузка медиатеки из каталога;
    - подготовка плейлиста воспроизведения.
3. Если настроек еще нет, откроется экран **Settings**:
    - **URL** — адрес компьютера с foobar2000, например `192.168.1.100`.
      Префикс `http://` можно не вводить — он добавится автоматически.
    - **Port** — порт сервера Beefweb, обычно `8880`. Поле можно оставить
      пустым, если порт уже указан в URL.
4. Вернитесь назад кнопкой «Назад» (стрелка с подписью в шапке). Настройки
   будут проверены и сохранены, после чего запуск повторится: при успешном
   соединении откроется экран альбомов, при ошибке — сообщение под формой.
   Пока идет проверка соединения, кнопка «Назад» заблокирована.

Библиотека импортируется заново при каждом запуске приложения, поэтому
изменения медиатеки подхватываются после перезапуска.

## Навигация

На главном экране воспроизведения шестеренка в шапке открывает настройки.
На остальных экранах внизу находится нижняя навигационная панель с пунктами:

-   **Genres** → **Artists** → **Albums** → **Tracks** — навигация
    по медиатеке;
-   **Playlists** — список плейлистов;
-   **Settings** — настройки.

Активный пункт подсвечен. На главный экран можно вернуться тапом
по мини-плееру внизу любого экрана библиотеки.

## Главный экран

На главном экране отображается обложка играющего альбома, название трека,
исполнитель, альбом, полоса прогресса и блок управления. Если воспроизводится
плейлист, вместо обложки альбома показывается заглушка плейлиста.

### Жесты на обложке

| Жест         | Действие                      |
| ------------ | ----------------------------- |
| Свайп влево  | Следующий трек                |
| Свайп вправо | Предыдущий трек               |

Вертикальные свайпы на обложке не выполняют действий.

### Полоса прогресса

Полоса изображает трек в виде «волны»: проигранная часть выделена цветом.
Под полосой слева — текущее время, справа — длительность, в центре — номер
трека в альбоме (`3 / 12`). Касание в любом месте полосы перематывает трек
на соответствующую позицию.

### Громкость

Слайдер громкости показывает уровень, полученный от плеера. Во время
перетаскивания значение применяется после отпускания пальца. Кнопка рядом
со слайдером включает и выключает mute.

### Кнопки воспроизведения

Кнопки «предыдущий», play/pause и «следующий» управляют текущим альбомом.
«Предыдущий» неактивен на первом треке, «следующий» — на последнем;
на время выполнения команды кнопки кратко блокируются.

Если команда завершилась ошибкой, сообщение появится под кнопками.

## Мини-плеер

На экранах библиотеки (жанры, исполнители, альбомы, треки) внизу находится
компактный блок текущего воспроизведения: обложка, названия трека,
исполнителя и альбома, тонкая полоса прогресса с перемоткой и те же три
кнопки управления. Тап по обложке или подписям трека открывает главный
экран.

## Навигация по медиатеке

Выбор фильтрует нижние уровни: жанр ограничивает список исполнителей,
исполнитель — список альбомов. Выбор сохраняется при переключении между
экранами меню.

### Жанры

Первым пунктом идет **All genres** (все альбомы), далее — список жанров
с количеством альбомов у каждого. Выбранный пункт подсвечивается.

### Исполнители

Список исполнителей с учетом выбранного жанра; число справа — количество
альбомов исполнителя в этом жанре. Пункт **All artists** снимает фильтр.

### Альбомы

Сетка альбомов по три колонки с обложками, заголовок сверху показывает
текущий контекст, например `Rock - Pink Floyd`. Тап по альбому загружает
его в foobar2000 и начинает воспроизведение с первого трека; карточка
текущего альбома подсвечена. Пока загрузка выполняется, сетка заблокирована.

Многодисковые альбомы упорядочены по дискам, затем по номерам треков.

### Треки

Список треков активного источника — текущего альбома или выбранного
плейлиста: порядковый номер, название, длительность.
У многодисковых альбомов треки сгруппированы по секциям с названием диска.
Тап по треку запускает его воспроизведение, текущий трек выделен.

### Плейлисты

Список пользовательских плейлистов foobar2000 с количеством треков у каждого.
Служебные плейлисты (в том числе `beefweb-catalog`) и пустые плейлисты
не показываются. Тап по плейлисту запускает его воспроизведение с первого
трека; выбранный плейлист подсвечен, на время загрузки список заблокирован.

## Настройки

Экран открывается шестеренкой в шапке главного экрана или пунктом Settings в нижней навигационной панели.

-   **URL** и **Port** — те же поля подключения, что и при первом запуске.
    Измененные значения проверяются соединением с сервером и сохраняются
    только при успехе; если ничего не менялось, выход происходит без
    проверки.
-   **Language** — язык интерфейса: English, Русский, Deutsch, Français,
    Español или 中文. Выбор применяется мгновенно ко всем экранам
    и сохраняется отдельно от формы подключения. При первом включении язык
    выбирается по системной локали устройства.
-   **Theme** — тема оформления: System, Light или Dark. По умолчанию
    используется системная тема устройства.

Ошибки проверки выводятся списком под формой.

## Сообщения об ошибках

| Ситуация                             | Что делать                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| Нет соединения с сервером            | Проверьте, что foobar2000 запущен, адрес и порт верны, а брандмауэр разрешает подключения |
| Плейлист `beefweb-catalog` не найден | Создайте его вручную и наполните медиатекой (см. README)                                  |
| Каталог пуст                         | Добавьте в него всю библиотеку                                                            |
| Каталог слишком велик                | В нем больше 100 000 треков — сократите содержимое                                        |
| Обложки не совпадают с библиотекой   | Содержимое каталога изменилось после импорта — обновите его и перезапустите приложение    |
| Плейлист `beefweb` не найден         | Он создается автоматически — проверьте права плагина Beefweb и повторите запуск           |
| Ошибка загрузки альбома в плеер      | Проверьте доступность файлов на сервере и повторите попытку                               |

Все сообщения показываются на языке интерфейса.

## Данные на устройстве

Приложение хранит локально:

-   адрес и порт сервера;
-   выбранный язык интерфейса и тема оформления;
-   последний выбранный альбом, трек и позицию воспроизведения
    (восстанавливаются при запуске);
-   кэш обложек (может очищаться системой автоматически).

Чтобы сбросить все данные, очистите данные приложения в настройках Android
или удалите и установите его заново.
